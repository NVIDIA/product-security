### Security Bulletin - NVIDIA DGX Spark - August 2026

Updated 2026-08-25

NVIDIA has released a software update for NVIDIA DGX Spark.<div>To protect your system, follow the guidance for OS updates in the <a href="https://docs.nvidia.com/dgx/dgx-spark/os-and-component-update.html">OS and Component Update Guide</a>.</div>

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-47626 | NVIDIA DGX Spark contains a vulnerability in the system firmware, where a privileged attacker could be able to cause an out-of-bounds write. | CVE-2026-24263 | NVIDIA DGX Spark contains a vulnerability in the system firmware, where a privileged attacker could be able to cause a NULL pointer dereference. A successful exploit of this vulnerability may lead to code execution, escalation of privileges, denial of service, information disclosure, and data tampering. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:H<br>/UI:N<br>/S:C<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:H) | 8.2 | HIGH | [CWE-476](https://cwe.mitre.org/data/definitions/476.html) | Code execution, escalation of privileges, data tampering, denial of service, information disclosure |
| CVE-2026-24262 | NVIDIA DGX Spark contains a vulnerability in the system firmware, where a privileged attacker could be able to cause an out-of-bounds write. A successful exploit of this vulnerability may lead to code execution, escalation of privileges, denial of service, information disclosure, and data tampering. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:H<br>/UI:N<br>/S:C<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:H) | 8.2 | HIGH | [CWE-787](https://cwe.mitre.org/data/definitions/787.html) | Code execution, escalation of privileges, data tampering, denial of service, information disclosure |

A successful exploit of this vulnerability might lead to information disclosure. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:H<br>/UI:N<br>/S:C<br>/C:H<br>/I:N<br>/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:H/UI:N/S:C/C:H/I:N/A:N) | 6.0 | MEDIUM | [CWE-125](https://cwe.mitre.org/data/definitions/125.html) | Information disclosure |
