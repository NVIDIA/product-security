### Security Bulletin: NVIDIA AIStore Framework - November 2026

Updated 2026-11-24

NVIDIA has released a software update for NVIDIA® AIStore™ framework.&nbsp;<div><span style="color: var(--text-color-primary); font-family: var(--psirt-font-family-sans);">To protect your system, download and install the latest version of the NVIDIA AIStore framework from the <a href="https://github.com/NVIDIA/aistore">NVIDIA/aistore</a> GitHub repo.</span></div>

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-65175 | NVIDIA AIStore contains a vulnerability in storage-target node-control authorization where an unauthenticated attacker could access administrative functions through a target's public interface. A successful exploit might lead to information disclosure, data tampering, or denial of service. | [CVSS:3.1<br>/AV:N<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H) | 9.8 | CRITICAL | [CWE-306](https://cwe.mitre.org/data/definitions/306.html) | Data tampering, denial of service, information disclosure |
| CVE-2026-100986 | NVIDIA AIStore contains a vulnerability in append-operation handle validation where an unauthenticated attacker could cause data to be appended to a file outside the intended storage location. A successful exploit might lead to code execution, denial of service, escalation of privileges, information disclosure, or data tampering. | [CVSS:3.1<br>/AV:N<br>/AC:H<br>/PR:N<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H) | 8.1 | HIGH | [CWE-73](https://cwe.mitre.org/data/definitions/73.html) | Code execution, escalation of privileges, data tampering, denial of service, information disclosure |
| CVE-2026-100985 | NVIDIA AIStore contains a vulnerability in object-copy destination validation where an unauthenticated attacker could use a crafted destination object name to write a file outside the configured storage location. A successful exploit might lead to code execution, denial of service, escalation of privileges, information disclosure, or data tampering. | [CVSS:3.1<br>/AV:N<br>/AC:H<br>/PR:N<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H) | 8.1 | HIGH | [CWE-22](https://cwe.mitre.org/data/definitions/22.html) | Code execution, escalation of privileges, data tampering, denial of service, information disclosure |

The NVIDIA risk assessment is based on an average of risk across a diverse set of installed systems and might not represent the true risk to your local installation. NVIDIA recommends evaluating the risk to your specific configuration.
