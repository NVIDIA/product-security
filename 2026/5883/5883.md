### Security Bulletin: - NVIDIA - TensorRT LLM - October 2026

Updated 2026-10-27

NVIDIA has released a software update for NVIDIA® TensorRT-LLM.&nbsp;<div>To protect your system, clone or update this software from the  <a href="https://github.com/NVIDIA/TensorRT-LLM">NVIDIA/TensorRT-LLM</a> GitHub repo.</div>

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-65119 | NVIDIA TensorRT-LLM for any platform contains a vulnerability in KvCacheAwareRouter tokenizer loading, where an attacker could cause inclusion of functionality from an untrusted control sphere. A successful exploit might lead to code execution, information disclosure, data tampering, and denial of service. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H) | 8.4 | HIGH | [CWE-829](https://cwe.mitre.org/data/definitions/829.html) | Code execution, data tampering, denial of service, information disclosure |
| CVE-2026-65120 | NVIDIA TensorRT-LLM contains a vulnerability where an attacker could cause a server-side request forgery. A successful exploit of this vulnerability might lead to information disclosure. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:C<br>/C:H<br>/I:N<br>/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:C/C:H/I:N/A:N) | 7.1 | HIGH | [CWE-918](https://cwe.mitre.org/data/definitions/918.html) | Information disclosure |
| CVE-2026-24269 | NVIDIA TensorRT-LLM contains a vulnerability where an attacker could cause a server-side request forgery. A successful exploit of this vulnerability might lead to information disclosure and data tampering. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:C<br>/C:H<br>/I:N<br>/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:C/C:H/I:N/A:N) | 7.1 | HIGH | [CWE-918](https://cwe.mitre.org/data/definitions/918.html) | Data tampering, information disclosure |

The NVIDIA risk assessment is based on an average of risk across a diverse set of installed systems and might not represent the true risk to your local installation. NVIDIA recommends evaluating the risk to your specific configuration.
