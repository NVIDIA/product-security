### Security Bulletin - Megatron LM - October 2026

Updated 2026-10-13

NVIDIA has released a software update for NVIDIA® Megatron LM.&nbsp;<div>To protect your system, clone or update this software to version 0.17.1 or later from the <a href="https://github.com/NVIDIA/Megatron-LM">NVIDIA/Megatron-LM</a> GitHub repo.</div>

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-65180 | NVIDIA Megatron-LM contains a vulnerability in checkpoint loading where an Attacker may cause an RCE by convincing a user to load a maliciously crafted file. A successful exploit of this vulnerability may lead to code execution, escalation of privileges, information disclosure, and data tampering. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:L<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H) | 7.8 | HIGH | [CWE-502](https://cwe.mitre.org/data/definitions/502.html) | Code execution, escalation of privileges, data tampering, information disclosure |
| CVE-2026-65110 | NVIDIA Megatron-LM contains a vulnerability in checkpoint loading where, an attacker could cause an RCE by convincing a user to load a maliciously crafted file. A successful exploit of this vulnerability might lead to code execution, escalation of privileges, information disclosure, and data tampering. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:L<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H) | 7.8 | HIGH | [CWE-502](https://cwe.mitre.org/data/definitions/502.html) | Code execution, escalation of privileges, data tampering, information disclosure |
| CVE-2026-65104 | NVIDIA Megatron-LM for all platforms contains a vulnerability in inference, where an attacker could cause hash collisions in the cache used for inference requests. A successful exploit of this vulnerability might lead to data tampering and partial information disclosure. | [CVSS:3.1<br>/AV:N<br>/AC:H<br>/PR:L<br>/UI:N<br>/S:C<br>/C:L<br>/I:H<br>/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:L/I:H/A:N) | 7.1 | HIGH | [CWE-328](https://cwe.mitre.org/data/definitions/328.html) | Data tampering, information disclosure |

The NVIDIA risk assessment is based on an average of risk across a diverse set of installed systems and might not represent the true risk to your local installation. NVIDIA recommends evaluating the risk to your specific configuration.
