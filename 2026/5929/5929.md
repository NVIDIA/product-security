### Security Bulletin: NVIDIA OpenShell - November 2026

Updated 2026-11-17

NVIDIA has released a software update for NVIDIA OpenShell™.<br>To protect your system, download and install the latest version of&nbsp;<a href="https://www.nvidia.com/en-us/ai/openshell/">NVIDIA OpenShell™</a>.

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)
