### Security Bulletin: TensorRT - November 2026

Updated 2026-11-17

NVIDIA has released a software update for NVIDIA® TensorRT.<br>To protect your system, clone or update this software to the latest version of TensorRT from the <a href="https://github.com/NVIDIA/TensorRT">NVIDIA/TensorRT</a> GitHub repo or the&nbsp;<a href="https://developer.nvidia.com/tensorrt/download/11x">TensorRT product page</a>.

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-100963 | NVIDIA TensorRT for Linux contains a vulnerability where a user could cause an integer overflow issue. A successful exploit of this vulnerability might lead to denial of service and data tampering. | [CVSS:3.1<br>/AV:N<br>/AC:L<br>/PR:N<br>/UI:R<br>/S:U<br>/C:N<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:H) | 8.1 | HIGH | [CWE-190](https://cwe.mitre.org/data/definitions/190.html) | Data tampering, denial of service |
| CVE-2026-65167 | NVIDIA TensorRT contains a vulnerability where a user could cause memory allocation with excessive size value by crafting a malicious TRT engine. A successful exploit of this vulnerability might lead to denial of service. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:N<br>/UI:R<br>/S:U<br>/C:N<br>/I:N<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H) | 5.5 | MEDIUM | [CWE-789](https://cwe.mitre.org/data/definitions/789.html) | Denial of service |

The NVIDIA risk assessment is based on an average of risk across a diverse set of installed systems and might not represent the true risk to your local installation. NVIDIA recommends evaluating the risk to your specific configuration.

### Security Updates

NVIDIA has released a software update for NVIDIA® TensorRT.<br>To protect your system, clone or update this software to the latest version of TensorRT from the <a href="https://github.com/NVIDIA/TensorRT">NVIDIA/TensorRT</a> GitHub repo or the&nbsp;<a href="https://developer.nvidia.com/tensorrt/download/11x">TensorRT product page</a>.

The following table lists the software products and versions affected, and the updated version available from nvidia.com that includes this security update.

| **CVE Addressed** | **Affected Products** | **Platform or OS** | **Affected Versions** | **Updated Version** |
| --------------------- | --------------------- | ----------------- | --------------------- | ------------------- |
| CVE-2026-65167 | TensorRT | All | 0 to 11.3 | 11.4 |
| CVE-2026-100963 | TensorRT | All | 0 to 11.2 | 11.3 |
