### Security Bulletin: Megatron Bridge - September 2026

Updated 2026-09-01

NVIDIA has released a software update for NVIDIA® Megatron Bridge.&nbsp;<div>To protect your system, clone or update this software to version 0.5.1 or later from the <a href="https://github.com/NVIDIA-NeMo/Megatron-Bridge">NVIDIA/Megatron-Bridge</a> GitHub repo.</div>

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)
