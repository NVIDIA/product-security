### Security Bulletin: NVIDIA Triton Inference Server - August 2026

Updated 2026-08-18

NVIDIA has released a software update for NVIDIA® Triton Inference Server. This update addresses the security issues listed below. To protect your system, update to NVIDIA Triton Inference Server version 26.06 or later.

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)
