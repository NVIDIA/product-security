### Security Bulletin: NVIDIA NemoClaw and OpenShell - August 2026

Updated 2026-08-25

NVIDIA has released a software update for NVIDIA®&nbsp; NemoClaw and OpenShell.<div>To protect your system, clone or update this software from the <a href="https://github.com/NVIDIA/NemoClaw">NVIDIA/NemoClaw</a>&nbsp;and <a href="https://github.com/NVIDIA/OpenShell">NVIDIA/OpenShell</a> GitHub repos.</div>

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)
