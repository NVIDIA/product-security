### Security Bulletin: NeMo Agent Toolkit - October 2026

Updated 2026-10-27

NVIDIA has released a software update for NVIDIA® NeMo Agent Toolkit<br>To protect your system, clone or update this software to version 1.9.0 or later from the <a href="https://github.com/NVIDIA/NeMo-Agent-Toolkit/tree/main">NVIDIA/NeMo-Agent-Toolkit</a>&nbsp;GitHub repo.

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)

### Details

This section provides a summary of potential vulnerabilities that this security update addresses and their impact. Descriptions use [CWE&trade;](https://cwe.mitre.org/), and base scores and vectors use [CVSS v3.1](https://www.first.org/cvss/specification-document) standards.

| **CVE ID** | **Description** | **Vector** | **Base Score** | **Severity** | **CWE** | **Impacts** |
| ---------- | ---------------- | ---------- | -------------- | ------------ | -------- | ------------ |
| CVE-2026-65145 | NVIDIA NeMo Agent Toolkit contains a vulnerability where a attacker could cause a missing authentication issue. This vulnerability might lead to code execution, escalation of privileges, data tampering, denial of service, and information disclosure. | [CVSS:3.1<br>/AV:N<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:C<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H) | 10.0 | CRITICAL | [CWE-306](https://cwe.mitre.org/data/definitions/306.html) | Code execution, escalation of privileges, data tampering, denial of service, information disclosure |
| CVE-2026-65151 | NVIDIA NeMo Agent Toolkit contains vulnerability where an attacker could cause a SQL injection issue. A successful exploit of this vulnerability might lead to data tampering, denial of service and information disclosure. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:N<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H) | 8.4 | HIGH | [CWE-89](https://cwe.mitre.org/data/definitions/89.html) | Data tampering, denial of service, information disclosure |

The NVIDIA risk assessment is based on an average of risk across a diverse set of installed systems and might not represent the true risk to your local installation. NVIDIA recommends evaluating the risk to your specific configuration.
