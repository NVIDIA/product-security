### Security Bulletin: NVIDIA Jetson Xavier Series, Jetson Orin Series, Jetson Thor Series, and IGX Thor Devices - November 2026

Updated 2026-11-24

NVIDIA has released a software update for NVIDIA® Jetson Linux.<div>To protect your system, download and install this software update from the APT server or <a href="https://developer.nvidia.com/embedded/downloads">Jetson Download Center</a> page, <a href="https://developer.nvidia.com/embedded/jetson-linux-archive">Jetson Linux Link</a> and <a href="https://developer.nvidia.com/igx-downloads?sortBy=igx_downloads%2Fsort%2Fdate%3Adesc">IGX Link</a>.</div><div><br></div>

Go to [NVIDIA Product Security](https://www.nvidia.com/security/)
