### Security Bulletin - NeMo Speech - August 2026

Updated 2026-09-22

NVIDIA has released a software update for NVIDIA® NeMo Speech.<div>To protect your system, clone or update this software to version 3.0 or later from the <a href="https://github.com/NVIDIA-NeMo/Speech">NVIDIA-NeMo/Speech</a>&nbsp;GitHub repo.</div><div>The following table summarizes the potential vulnerabilities addressed by this security update and their impact. | CVE-2026-65178 | NVIDIA NeMo contains a vulnerability in its dataset-loading workflow where a maliciously crafted model_config.yaml can inject unsafe parameters. A successful exploit of this vulnerability may lead to code execution, data tampering, denial of service, and information disclosure. | [CVSS:3.1<br>/AV:L<br>/AC:L<br>/PR:L<br>/UI:N<br>/S:U<br>/C:H<br>/I:H<br>/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H) | 7.8 | HIGH | [CWE-502](https://cwe.mitre.org/data/definitions/502.html) | Code execution, escalation of privileges, data tampering, information disclosure |
